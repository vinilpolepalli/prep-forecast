# Prep Forecast

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Marble (joinmarble.ai) works in. Not affiliated with or endorsed by Marble.

Demand forecast to prep and purchasing desk for one fictional fast-casual restaurant. Every number (covers, menu mix, recipes, stock, costs) is invented sample data; flags come from plain deterministic arithmetic, not a learned model. Edit covers and the order, risk flags and prep lists recompute.

Static export of a Next.js app. Built with Claude Code.
